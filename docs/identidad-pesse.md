# Identidad Pesse — guía web inicial

## Marca
PESSE es un medio digital de noticias. El logotipo de referencia proporcionado por la marca tiene las letras PESSE y un micrófono integrado en la P. La versión principal usa verde profundo.

## Paleta digital provisional
- Verde principal: **#1D503E** (aproximación visual al arte proporcionado).
- Verde oscuro: **#143C2F**.
- Verde suave: **#A8D3B8**.
- Texto carbón: **#17231E**.
- Fondo claro: **#F8F9F7**.
- Blanco: **#FFFFFF**.

## Usos
- Header blanco, logotipo verde.
- Footer verde oscuro, logotipo blanco.
- Formularios y botones primarios verdes.
- Categorías y etiquetas de artículos verdes, con contraste legible.
- Favicon: isotipo P/micrófono.
