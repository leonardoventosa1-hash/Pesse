# Pesse 2.0

Nuevo portal periodístico de Pesse. Proyecto independiente de Finanzas.

## Objetivo
Recrear la identidad visual pública del sitio actual y desarrollar un portal moderno con Next.js, TypeScript y Supabase. El código se construirá primero en una rama de desarrollo y no se desplegará hasta revisar el diseño y la seguridad.

## Etapas
1. Base pública: portada, noticias, categorías y diseño responsive.
2. Panel editorial: autenticación, borradores, artículos, autores e imágenes.
3. SEO, redes sociales, formularios, validaciones y lanzamiento controlado.

**Estado:** estructura inicial en desarrollo; no conectar claves privadas ni publicar contenido de prueba.
